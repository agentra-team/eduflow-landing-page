## macOS will not open EduFlow

The installer is not signed yet with an Apple certificate, so the first time you open it macOS blocks it and says it cannot check the app. You only do this once:

1. Open EduFlow from **Applications**; when macOS says the app cannot be opened, click **Done**.
2. Open **System Settings** › **Privacy & Security**, scroll down to **Security**, click **Open Anyway** next to the line about EduFlow, then enter your Mac password.
3. Click **Open** in the dialog that asks again.

The full steps, with how to pick the right file for your Mac chip, are in the "First launch" step of [Install on macOS](/en/docs/install-macos). Only open files downloaded from the EduFlow [Download](/en/download) page.

## Windows SmartScreen blocks the installer

The installer is not signed yet with a Microsoft certificate either, so Windows Defender SmartScreen shows **"Windows protected your PC"** with the publisher **Unknown publisher**.

1. Click **More info**.
2. Check that the file name is the file you just downloaded from the EduFlow Download page.
3. Click **Run anyway**.

To make sure the file was not altered, compare the SHA-512 checksum on the Download page with the output of this command (open PowerShell in the folder that holds the file):

<CodeBlock code={'certutil -hashfile "EduFlow Setup <version>.exe" SHA512'} copyLabel="Copy" copiedLabel="Copied" />

[Install on Windows](/en/docs/install-windows) has every step.

## The app shows a general error or cannot export a file

- <Ui>Có lỗi trong app. Thử lại; nếu lặp lại, khởi động lại EduFlow.</Ui> (There is an error in the app. Try again; if it repeats, restart EduFlow.)
- <Ui>Không gọi được tiến trình chính của app. Khởi động lại EduFlow.</Ui> (Cannot reach the app's main process. Restart EduFlow.)
- <Ui>Chưa xuất được tệp. Thử lại; nếu lặp lại, khởi động lại EduFlow.</Ui> (The file could not be exported yet. Try again; if it repeats, restart EduFlow.)
- <Ui>Không mở hoặc ghi được kho dữ liệu trên máy này.</Ui> (Cannot open or write the data store on this computer.) and <Ui>EduFlow không mở được dữ liệu trên máy này.</Ui> (EduFlow cannot open the data on this computer.) are the two messages when the data store cannot be opened; the data folder is in the last section. Contact Agentra with the message.

EduFlow allows only one running copy per data folder, because two processes writing one data store corrupt it.

## Updating to a new version

This version does not update itself inside the app. When you need a newer version, go to the [Download](/en/download) page, download the latest installer and install it as the first time (macOS: drag it into **Applications**; Windows: run the **.exe** file). Your projects live in the app's own data folder, separate from the install folder.

## Uninstalling and keeping your data

- **macOS:** quit EduFlow, then drag **EduFlow** from **Applications** to the Trash.
- **Windows:** open Windows **Settings**, choose **Apps**, find **EduFlow** and click **Uninstall**.

Your project data lives in the app's own data folder, separate from the install folder (see the next section). Files you exported (PDF, DOCX...) are wherever you chose to save them.

<Callout kind="warning">The <Ui>Đăng xuất và xoá</Ui> (Sign out and delete) button in <Ui>Cài đặt</Ui> (Settings) deletes the whole project store on that computer and asks you to type <Ui>XOÁ KHO</Ui> (DELETE STORE) to confirm. Uninstalling does not need this button; use it only when you really want to wipe the data on the computer.</Callout>

## Where your data is

EduFlow keeps its data in the app's data folder, named `EduFlow`:

| Operating system | Folder |
|---|---|
| macOS | `~/Library/Application Support/EduFlow` |
| Windows | Usually `%APPDATA%\EduFlow`, that is `C:\Users\<user name>\AppData\Roaming\EduFlow` (not yet checked on a real Windows computer; if you do not see it, type `%APPDATA%` in the File Explorer address bar and look for the `EduFlow` folder) |

Inside that folder:

- `store/`: the project store (the `eduflow.db` database) and its attached files.
- `secrets/`: information about this computer, encrypted by the operating system.
- `machine-settings.json`: this computer's own choices, such as opening the assistant panel at start.
- `app-state.json`: the window position and the last snapshot of the key and cost state.
